侧边栏位置 检测中…

侧边栏在左侧还是右侧，是 Chrome 的全局设置，扩展无法用 API 修改 —— Chrome 的 sidePanel 只提供 getLayout() 读取布局， 没有对应的 setLayout()。所以这里只能帮你确认当前在哪一侧。

改法：Chrome 菜单 → 设置 → 外观 →「侧边栏」→ 选「在左侧显示 / 在右侧显示」； 也可以右键点击侧边栏边缘，直接选「移到左侧 / 移到右侧」。 这个设置对所有侧边栏内容生效，不只是本扩展。

搜索快捷键 —

两条各管一摊：任意网页那条在哪儿都能唤出搜索（有客户页面时是浮在页面上的搜索框）， 绑定由 Chrome 保管；插件页面内那条只在插件的侧边栏 / 标签页里生效，存本机偏好。

插件页面内 —

「任意网页」那条只能改在 Chrome 里 —— 浏览器不允许扩展自己设定全局快捷键 （MV3 的 chrome.commands 只有 getAll()，没有 update()）， 点左边按钮会直接把你送到 Chrome 的快捷键设置页。显示成 「未设置 / 未生效」说明浏览器里那条没绑上，多半与别的扩展或系统快捷键撞了。 「插件页面内」那条点「修改」后直接按组合键即可（必须含 Ctrl / ⌘ / Alt 之一），Esc 取消。
