侧边栏位置 检测中…

侧边栏在左侧还是右侧，是 Chrome 的全局设置，扩展无法用 API 修改 —— Chrome 的 sidePanel 只提供 getLayout() 读取布局， 没有对应的 setLayout()。所以这里只能帮你确认当前在哪一侧。

改法：Chrome 菜单 → 设置 → 外观 →「侧边栏」→ 选「在左侧显示 / 在右侧显示」； 也可以右键点击侧边栏边缘，直接选「移到左侧 / 移到右侧」。 这个设置对所有侧边栏内容生效，不只是本扩展。

侧边栏自动隐藏 —

开启后，鼠标离开侧边栏并停留一小会儿，面板会自动收起，把宽度还给网页； 再按 Alt+Shift+N 即可重新打开（也可以在 Chrome 的扩展快捷键页改成自己顺手的手势）。

延迟是「鼠标离开后等多久才收起」。焦点落在输入框或下拉框上时不会收起 —— 原生下拉的选项弹窗属于浏览器界面，鼠标移过去在网页看来等于离开了文档。

贴边浮窗 —

在 Salesforce 页面上贴一条感应边，鼠标靠过去就滑出这个工具面板。 侧边栏本身做不到这一点：Chrome 规定 sidePanel.open() 只能由 点击 / 快捷键 / 右键菜单触发，鼠标移动不算用户动作，所以「靠边即显示」 只能由浮窗来实现。

改完立即生效，无需刷新页面 —— 只对已打开的 Salesforce 标签页生效； 新开的标签页会自动带上。浮窗与侧边栏是两套独立入口，可以同时开。
